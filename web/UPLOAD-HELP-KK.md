# Фото/құжат жүктеу

Жаңа нұсқа **Supabase жеке қоймасын** пайдаланады. Firebase Storage үшін Blaze қосудың қажеті жоқ.

Бір рет баптау: [SUPABASE-SETUP-KK.md](SUPABASE-SETUP-KK.md).

Файлды таңдағанда автоматты жіберіледі: пайыз көрінеді, соңында күйі «Тексерілуде» болады. PDF/JPG/PNG, 5 МБ дейін. HEIC/HEIF файлын JPG/PNG етіп экспорттаңыз.

Админ: Өтініштер → Ашу → файл атауы. Файл панель ішіндегі қарау терезесінде ашылады, жүктеп алу мүмкіндігі де бар.

- STORAGE_NOT_CONFIGURED: ашық функция адресі немесе функция ортасы әлі бапталмаған.
- ACCESS_DENIED: Firebase аккаунтын, админ рөлін және жаңартылған Firestore ережелерін тексеріңіз.
- ORIGIN_NOT_ALLOWED: функцияның ALLOWED_ORIGINS тізіміне сайттың нақты origin адресін қосыңыз.
- STORAGE_UNAVAILABLE: Supabase жобасының белсенділігін, bucket пен функцияны, тегін лимиттерді тексеріңіз.
- Файл жүктеліп, бірақ күйі өзгермесе: Firestore ережесін жаңартыңыз, storage_provider өрісі рұқсат етілген болуы керек.

Қате файлдың қасында көрсетіледі. Сол файлды қайта таңдауға болады. Ескі файл жаңа файл сақталғанша өшірілмейді.
