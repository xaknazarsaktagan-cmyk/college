# Фото/құжат жүктеу

Файлды таңдағаннан кейін «Жүктелуде…» шығып, пайыз көрсетіледі. Соңында құжат «Тексерілуде» күйіне өтеді. Файл автоматты жіберіледі; екінші рет «Жүктеу» басудың қажеті жоқ. Қолдау: PDF, JPG, PNG, 5 МБ дейін. HEIC/HEIF болса, JPG/PNG етіп экспорттаңыз.

Қате шықса, ол файлдың қасында қалады. Сол файлды қайта таңдауға немесе жүктеуді тоқтатуға болады. Ескі файл жаңа файл толық сақталғанша өшірілмейді.

Нақты Firebase қоймасын тексеру (жоба иесі):

1. Firebase Console → Storage: bucket шынымен құрылған ба? «Get started» шықса, қойма әлі құрылмаған. Егер Console billing/Blaze қосуды сұраса, бұл жоба иесінің жеке шешімі; код оны автоматты қосқан жоқ.
2. Bucket атауы frontend/js/firebase-config.js ішіндегі storageBucket-пен дәл сәйкес болуы керек.
3. Storage → Rules ішінде firebase/storage.rules жариялаңыз. Console сұраса, ережелердің Firestore-ға қол жеткізуін қосыңыз. Firestore → Rules ішінде firebase/firestore.rules жарияланған болсын.
4. storage/unauthorized — авторизацияны және ережелерді тексеріңіз. Қауіпсіздік ережелерін ашық режимге ауыстырмаңыз.
5. storage/bucket-not-found — қойма құрылмаған немесе атауы қате.
6. storage/quota-exceeded — жоба лимитін/billing күйін Console-да тексеріңіз.
7. storage/retry-limit-exceeded — желіні және Storage қолжетімділігін тексеріңіз; браузердің Network панеліндегі нақты қатені қараңыз.

Жүктелген файлды **ашу** кезінде ғана CORS қатесі болса, bucket-ке CORS конфигурациясын қолдану керек. firebase/storage.cors.json ішіне жергілікті адрес пен https://college-frontend-kohl.vercel.app енгізілген. Бұл файлды GitHub-қа салу Firebase-ке конфигурацияны автоматты қолданбайды. Жоба иесінің Cloud Shell сессиясында, өз bucket атауын көрсетіп орындаңыз:

```
gcloud storage buckets update gs://YOUR_BUCKET --cors-file=firebase/storage.cors.json
```

Нақты пайдаланушы файлдары бұлттағы тесттерде қолданылмады. Браузерлік тесттер Firebase SDK алмастырғышымен жүктеу, рұқсат қатесі, қайталау, тоқтату және формат тексерулерін қамтиды. Нақты bucket-ке жазу бөлек тексерілуі керек.
