# Админ панелі және жеке чат

## Жаңартуды орнату

1. Қазіргі жобаңыздың сақтық көшірмесін жасаңыз.
2. Архивтің `web` қалтасын жобаңыздағы `web` қалтасымен біріктіріңіз.
3. **Өзіңіз толтырған `frontend/js/firebase-config.js` файлын сақтаңыз.** Бұл жаңарту архивіне ол әдейі қосылмады. Firebase параметрлерін қайта енгізудің қажеті жоқ.
4. Firebase Console → Firestore Database → Rules ішіне `firebase/firestore.rules` мазмұнын қойып, Publish басыңыз. Storage → Rules үшін `firebase/storage.rules` қолданыңыз. Ережелерсіз чат жұмыс істемейді. Бұрынғы деректер өшірілмейді.
5. `web` каталогынан `docker compose up -d --force-recreate web` орындаңыз. Браузерде Ctrl+Shift+R басыңыз.

## Админ аккаунтын Firebase Console арқылы құру (ең оңай жол)

Бұл архив Firebase жобаңызда аккаунтты автоматты түрде құрмайды. Тек жоба иесі админ рөлін береді.

1. Firebase Console → Authentication → Users → Add user.
2. Email: `admin@gmail.com`. Құпиясөзді чаттағы ұсыныстан алыңыз немесе өзіңіз таңдаңыз. Құпиясөз бұл архивте жоқ. Егер email бұрын тіркелсе, жаңа аккаунт құрмай, сол аккаунттың UID-ын пайдаланыңыз; оның құпиясөзі автоматты өзгермейді.
3. Құрылған пайдаланушының **UID** мәнін көшіріңіз.
4. Firestore Database → Data → `users` коллекциясы → Add document. Document ID ретінде дәл сол UID енгізіңіз.
5. Барлық төмендегі өрістерді **string** түрінде қосыңыз:
   - `name`: `Қабылдау комиссиясы`
   - `email`: `admin@gmail.com`
   - `role`: `admin`
   - `phone`: бос жол
   - `iin`: бос жол
   - `created_at`: ағымдағы күннің ISO форматы, мысалы `2026-11-01T00:00:00.000Z`
   Егер осы UID профилі бұрын болса, жаңа құжаттың орнына оның `role` өрісін `admin` етіп өзгертіңіз, өзге деректерін сақтаңыз.
6. Сайттағы кәдімгі кіру формасынан админ email және құпиясөзімен кіріңіз. Админ `/admin.html` бетіне өтеді. Мекенжайды білу админ құқығын бермейді.

## Панельде не бар

- Жіберілген барлық өтініштер: аты-жөні, email, телефон, ЖСН, бағдарлама, ҰБТ, оқу тілі, жатақхана таңдауы.
- Құжатты ашу, қабылдау немесе себебін жазып қайтару.
- Өтінішті емтихан кезеңіне ауыстыру, қабылдау не бас тарту. Абитуриент шешімді кабинетінде көреді.
- Өтініштің «Ашу» батырмасынан кейін «Чат» арқылы жеке сөйлесу.
- Абитуриент кабинетінде «Комиссиямен чат» батырмасы.
- Хабарлар Firestore-да сақталады. Ашық чат 3 секунд сайын жаңарады. Жабық чатта push-хабарлама жоқ.
- Өзге абитуриенттің чатын оқу, админ атынан жазу, хабарды өзгерту/өшіру ережелермен тыйым салынған.

## Қосымша: сенімді компьютерден CLI арқылы админ құру

Console жолын қолдансаңыз, бұл бөлім қажет емес.

Node.js 22 және `npm ci` қажет. `tools/create-admin.mjs` Firebase Admin SDK пайдаланады. Google Application Default Credentials арқылы жобаға Auth және Firestore басқару рұқсаты керек. Қызметтік аккаунттың JSON кілтін ешқашан frontend-ке, архивке немесе Git-ке қоспаңыз. Оны осы жоба қалтасынан тыс сақтаңыз.

PowerShell-де, өзіңіздегі кілттің нақты жолын көрсетіңіз:

```powershell
$env:GOOGLE_APPLICATION_CREDENTIALS = "C:\secure\service-account.json"
node tools/create-admin.mjs
Remove-Item Env:GOOGLE_APPLICATION_CREDENTIALS
```

Жоба ID: `xako-cours`. Email сұрағында Enter бассаңыз `admin@gmail.com` таңдалады. Құпиясөз терминалда жасырын енгізіледі, файлға не журналға жазылмайды. Құрал бұрынғы аккаунттың құпиясөзін ауыстырмайды; email бұрын бар болса тоқтайды.

## Тексеру нәтижелері

- SDK build және JavaScript синтаксис тексерулері өтті. Firebase Authentication эмуляторында тіркелу, шығу, кіру және құпиясөз ауыстыру тесті өтті (1 тест).
- Chromium браузерінде SDK тесттік алмастырғышымен: тіркелу, кіру, өтініш, PDF, жеке админ, шешім, екіжақты чат, қайта кіргенде тарихты оқу, HTML мәтінін қауіпсіз көрсету, 390 px ені тексерілді.
- Бұл браузерлік тексеру нақты Firebase рұқсаттарының тексеруі емес.
- `npm run test:rules` осы ортада эмулятор JAR-ын жүктеу кезінде HTTP 403 «Domain forbidden» қатесімен тоқтады. Қауіпсіздік ережелерінің жаңа тесттері жазылды, бірақ осы ортада орындалған жоқ. Қалыпты желісі бар компьютерде `npm ci`, `npm run test:rules`, `npm run test:auth` орындаңыз.
- Нақты Firebase жобаңызға қосылу, ережелерді жариялау және нақты админ аккаунтын құру бұл ортадан орындалған жоқ.
